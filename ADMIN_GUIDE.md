# Руководство администратора VStore

## Первый запуск

1. Установите Node.js LTS и Git. Для публикации дополнительно установите GitHub CLI с [cli.github.com](https://cli.github.com/).
2. Дважды щёлкните `START_ADMIN.bat`. Панель откроется на `http://127.0.0.1:4178` и доступна только на этом компьютере.
3. Для подключения GitHub откройте терминал в папке V Store и выполните `gh auth login`. Следуйте официальному входу через браузер.
4. Инициализируйте Git и создайте репозиторий согласно `DEPLOYMENT.md`. Убедитесь, что `gh repo view` показывает нужный репозиторий.

## Карточка и IPA

В панели выберите «Приложения» → «Добавить приложение». Заполните обязательные поля. ID строится из названия; черновик можно сохранить без IPA. Для публикации укажите источник, отметьте подтверждение права на распространение и выберите `.ipa`. Панель проверяет расширение, открывает архив и ищет `Payload/*.app/Info.plist`, считает SHA-256, размер и пытается извлечь Bundle ID, версию, имя и MinimumOSVersion.

Нажмите «Опубликовать». Администратор должен иметь настроенный `gh` и репозиторий. Панель создаёт GitHub Release с тегом `id-version`, загружает IPA как Release asset, сохраняет ссылку и SHA-256 в `data/apps.json`, затем делает commit и push. Ветка по умолчанию должна быть `main`. GitHub Actions соберёт и опубликует сайт. Если git push завершится неудачно, релиз уже создан: сохраните сообщённую ошибку, проверьте `data/apps.json`, затем закоммитьте изменения вручную.

Теги релизов уникальны: повторная публикация той же версии остановится, пока не будет увеличен номер версии. Загрузки IPA хранятся в GitHub Releases, а не в Git.

## Редактирование и категории

Редактируйте приложения из таблицы панели. Удаление удаляет запись каталога, но не удаляет уже опубликованный GitHub Release. Черновики не видны на публичном сайте. Категории хранятся в `data/categories.json`; для новой категории добавьте объект с уникальным `id`, `name`, `icon`, `description`.

Важное ограничение текущей версии: сохранение черновика, редактирование JSON и создание Release реализованы. Снятие с публикации означает изменение `status` на `draft` через редактор/JSON; управление категориями выполняется напрямую в JSON. Изображения приложения загружаются в `public/` вручную и не являются частью IPA upload.
